# Language Translation Tool 🌍

## 📌 About the Project
The Language Translation Tool is a web-based application that helps users translate text from one language to another quickly and easily. It uses the MyMemory Translation API to provide translations between multiple languages through a simple and user-friendly interface.

## ✨ Features
- Translate text between multiple languages.
- Select source and target languages.
- Get translated text instantly.
- Copy translated text easily.
- Simple and responsive user interface.
- Backend integration using Node.js and Express.js.
- Uses the MyMemory Translation API.
- No API key required for basic translation.

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Translation API:** MyMemory Translation API
- **Package Manager:** npm

## ⚙️ Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/JEEVITHA1406/Language-Translation-Tool
```

### 2. Navigate to the Project Folder
```bash
cd language_translation_tool
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Application
```bash
npm start
```

### 5. Open in Browser
Visit:
```text
http://localhost:3000
```

## 🚀 How to Use
1. Open the application in your browser.
2. Select the source language.
3. Select the target language.
4. Enter the text you want to translate.
5. Click the Translate button.
6. View and copy the translated text.

## 🔗 Translation API
This project uses the [MyMemory Translation API](https://mymemory.translated.net/) to perform text translation.

## 🎯 Project Objective
The main objective of this project is to develop an easy-to-use language translation application that helps users overcome language barriers and communicate across different languages.
